# Session Panel 버튼 행 확장

**Parent:** [`_index.md`](../_index.md)

## Why

기존 세션 패널에는 리듬게임 시작과 사운드 조절 버튼만 있어, 악기 가이드와
멀티플레이 기능으로의 진입점이 없다. 사용자가 기존 패널에서 바로 두 기능으로
전환할 수 있어야 한다.

## What

세션 패널의 기존 버튼 행에 "가이드"와 "멀티플레이" 버튼 2개를 추가한다.
기존 버튼(리듬게임 시작, 사운드 조절)과 동등한 크기·스타일로 수평 나열한다.

- 버튼 행에 "가이드"와 "멀티플레이" 버튼이 기존 버튼과 나란히 표시된다.
- "가이드" 버튼을 누르면 악기 가이드 패널이 열린다.
- "멀티플레이" 버튼을 누르면 멀티플레이 로비 패널이 열린다.
- 이미 다른 패널이 열려 있을 때 버튼을 누르면 열린 패널이 닫히고 새 패널이 열린다.

## Behavior

- **Given** 세션 패널이 표시된 상태
  **When** 사용자가 "가이드" 버튼을 누름
  **Then** 악기 가이드 패널이 열림

- **Given** 세션 패널이 표시된 상태
  **When** 사용자가 "멀티플레이" 버튼을 누름
  **Then** 멀티플레이 로비 패널이 열림

- **Given** 어떤 패널이 이미 열린 상태
  **When** 다른 버튼을 누름
  **Then** 기존 패널이 닫히고 새 패널이 열림
