# 악기 연주 방법 가이드 패널

**Parent:** [`_index.md`](../_index.md)

## Why

VR 환경에서 악기를 처음 접하는 사용자는 연주 방법을 알기 어렵다. 인앱
가이드 패널이 이미지와 설명 텍스트로 연주 방법을 단계별로 안내하면, 별도
매뉴얼 없이도 악기를 빠르게 익힐 수 있다.

## What

세션 패널의 "가이드" 버튼으로 열리는 독립 UI 패널. 악기별 연주 가이드를
이미지(가로 2개) + 텍스트 조합으로 페이지 단위로 표시하며, 상단 탭으로
악기를 선택하고 Prev/Next 버튼으로 페이지를 탐색한다.

- 패널 상단에 악기 탭 UI(드럼 / 피아노 / 트롬본, 이후 악기 추가 시 탭 추가).
- 악기가 앵커에 부착된 상태에서는 해당 악기 탭만 표시된다.
- 악기가 앵커에 없을 때는 모든 악기 탭이 표시되며 탭으로 악기 선택 가능.
- 각 페이지는 이미지 2개(가로 배치) + 텍스트 1개로 구성.
- Prev / Next 버튼으로 선택된 악기 안에서 페이지를 이동한다.
- 이미지는 `Tutorial/<악기명>/01`, `Tutorial/<악기명>/02` … 형식의 폴더 구조로 저장되며, 번호 순서대로 페이지에 대응한다.
- 이미지 원본 크기가 페이지마다 다를 수 있으므로 UI 컨테이너 크기에 맞춰 스케일링하여 표시한다.
- 텍스트 데이터는 추후 개발자가 직접 작성하며, 초기 구현에는 플레이스홀더 포함.

## Behavior

- **Given** 악기가 앵커에 부착된 상태에서 가이드 패널이 열림
  **When** 패널이 표시됨
  **Then** 해당 악기 탭만 활성화되고 그 악기의 첫 번째 페이지가 표시됨

- **Given** 악기가 앵커에 없는 상태에서 가이드 패널이 열림
  **When** 패널이 표시됨
  **Then** 모든 악기 탭이 표시되며 기본(첫 번째) 탭의 첫 페이지가 표시됨

- **Given** 가이드 패널이 열려 있는 상태에서 악기를 앵커에 부착
  **When** 악기 앵커 상태 변화 이벤트가 발생
  **Then** 해당 악기 탭만 표시되도록 즉시 전환되고 첫 페이지로 이동

- **Given** 현재 페이지가 선택된 악기의 마지막 페이지
  **When** 사용자가 Next 버튼을 누름
  **Then** Next 버튼이 비활성화 상태로 표시됨

- **Given** 현재 페이지가 첫 페이지
  **When** 사용자가 Prev 버튼을 누름
  **Then** Prev 버튼이 비활성화 상태로 표시됨
