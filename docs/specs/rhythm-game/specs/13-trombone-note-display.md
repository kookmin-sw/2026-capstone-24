# Trombone Note Display

**Parent:** [`_index.md`](../_index.md)

## Why

트롬본은 파셜(배음)과 슬라이드 포지션 두 축으로 음을 결정하므로, 기존 피아노의 단일
평면 패널로는 플레이어가 어느 배음 자세를 취하고 슬라이드를 어디에 위치시켜야 하는지
직관적으로 전달할 수 없다. 파셜별 독립 패널을 트롬본 앞 수평 반원형으로 배치하면
플레이어는 자연스럽게 해당 파셜 방향을 바라보며 슬라이드 위치를 조정하게 된다.

## What

트롬본 세션이 시작되면 5개의 파셜(배음) 패널이 트롬본 앞 수평 반원형으로 나타나고,
각 패널에 해당 파셜의 노트가 표시된다.

- 트롬본 악기를 잡은 상태에서 리듬게임 세션이 시작되면 5개 파셜 패널이 트롬본 앞
  수평 반원형으로 나타난다.
- 각 패널은 파셜 하나에 대응하며(파셜 0~4), 트롬본 축에 수직하게 배치된다.
- 노트는 차트가 요구하는 슬라이드 포지션의 이론적 3D 위치에서 스폰해
  트롬본 본체(판정선)를 향해 이동한다.
- 차트의 MIDI 노트는 InstrumentLaneConfig를 통해 파셜 인덱스(0~4)로 매핑된다.
- 트롬본이 아닌 악기를 잡은 세션에서는 이 디스플레이가 표시되지 않는다.

## Behavior

- **Given** 플레이어가 트롬본을 잡고 세션을 시작할 때
  **When** 세션 리드인이 시작될 때
  **Then** 트롬본 앞 수평 반원형으로 5개 파셜 패널이 나타나고,
          각 파셜의 차트 노트가 해당 패널에 낙하하기 시작한다

- **Given** 트롬본 세션이 진행 중일 때
  **When** 차트에서 파셜 2(중간 배음) 노트가 스폰될 때
  **Then** 파셜 2 패널에 노트가 요구 슬라이드 포지션의 이론적 3D 위치에서 생성되어
          판정선 방향으로 이동한다

- **Given** 트롬본 세션이 진행 중일 때
  **When** 플레이어가 올바른 파셜+슬라이드 포지션을 유지한 채 노트가 판정선에 도달할 때
  **Then** Perfect / Good / Miss 판정이 발생한다

- **Given** 차트에 트롬본 트랙이 있고 플레이어가 트롬본을 잡지 않은 경우
  **When** 세션이 시작될 때
  **Then** 트롬본 트랙은 자동 반주로 발화되고, 파셜 패널은 표시되지 않는다

## Out of Scope

- 피아노·드럼 등 다른 악기의 노트 디스플레이 변경
- 슬라이드 7포지션을 패널 내 서로 다른 레인으로 분리하는 레이아웃
  (파셜 단위 1패널 — 슬라이드 포지션은 스폰 위치로만 시각화)
- 판정 타이밍 로직 변경 (Judgment sub-spec 담당)
- 트롬본 파셜 개수 또는 슬라이드 포지션 수 변경
