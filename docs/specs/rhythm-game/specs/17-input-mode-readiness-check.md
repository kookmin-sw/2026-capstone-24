# Input Mode Readiness Check

**Parent:** [`_index.md`](../_index.md)

## Why

세션 패널의 플레이 버튼을 눌렀을 때 악기가 요구하는 입력 방식(핸드 트래킹 vs 컨트롤러)과
현재 활성 XR 입력 방식이 달라 리듬게임을 즉시 시작할 수 없는 상황이 있다. 사용자는 입력
방식을 바꾸는 데 시간이 걸리는데 게임이 그냥 시작되면 조작 불가 상태로 곡이 진행된다.
플레이 직전에 입력 방식 일치 여부를 확인하고, 불일치 시 명확한 안내로 사용자가 올바른
방식을 준비하게 한다.

## What

리듬게임 플레이 버튼을 클릭할 때 현재 악기에 설정된 필요 입력 방식과 실제 활성 XR 입력
방식을 비교하고, 불일치 시 안내 UI로 게임 시작을 차단한다. 올바른 입력 방식이 감지되면
자동으로 게임이 시작된다.

- 각 악기 prefab에는 "필요 입력 방식" 설정(핸드 트래킹 / 컨트롤러 / 제한 없음)이 인스펙터 필드로 존재한다.
- 플레이 버튼 클릭 시점에 현재 XR 입력 모드를 확인해 악기 요구 모드와 비교한다.
- 일치하거나 악기가 "제한 없음"이면 즉시 게임이 시작된다 (기존 흐름 유지).
- 불일치 시 게임을 시작하지 않고 안내 UI를 표시한다.
- 안내 UI는 필요 입력 방식을 알려주는 텍스트와 선택적 이미지(인스펙터에서 할당)를 포함한다.
- 안내 UI가 표시된 상태에서 올바른 입력 방식으로 전환되면 UI가 사라지고 자동으로 게임이 시작된다.

## Behavior

- **Given** 피아노(필요 입력 방식: 핸드 트래킹)가 활성 악기이고, 현재 XR 입력이 컨트롤러 모드인 상태
  **When** 플레이 버튼을 클릭
  **Then** 게임이 시작되지 않고, 안내 UI가 표시되어 핸드 트래킹으로 전환하라는 메시지가 보인다

- **Given** 안내 UI가 표시 중이고, 사용자가 Quest 설정에서 핸드 트래킹으로 전환
  **When** 앱이 핸드 트래킹 활성을 감지
  **Then** 안내 UI가 닫히고 리듬게임이 자동으로 시작된다

- **Given** 트롬본(필요 입력 방식: 컨트롤러)이 활성 악기이고, 현재 XR 입력이 컨트롤러 모드인 상태
  **When** 플레이 버튼을 클릭
  **Then** 기존과 동일하게 즉시 게임이 시작된다

- **Given** 필요 입력 방식이 "제한 없음"으로 설정된 악기가 활성 악기인 상태
  **When** 플레이 버튼을 클릭
  **Then** 현재 입력 방식과 무관하게 즉시 게임이 시작된다

## Out of Scope

- Quest 시스템 메뉴를 앱에서 직접 열거나 제어하는 기능
- 앱 내에서 자동으로 입력 모드를 전환하는 기능
- 입력 모드 외 다른 게임 시작 사전 조건 확인(악기 볼륨, 네트워크 연결 등)
- 안내 UI에 Quest 설정 화면 진입 딥링크 제공
