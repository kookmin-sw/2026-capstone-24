# 멀티플레이 로비 패널 UI

**Parent:** [`_index.md`](../_index.md)

**Tech Spec:** skipped

## Why

기존 04-presence-ui의 로비 패널 plan을 대체하는 UI 설계. VR 환경에서 방
생성과 참가를 한 화면에서 처리하는 좌/우 분리 레이아웃과, 비밀번호 방
입장 시 오버레이 흐름을 규정한다. 백엔드 연동은 이후 별도로 다룬다.

## What

세션 패널의 "멀티플레이" 버튼으로 열리는 독립 UI 패널.
좌측 방 생성 폼 + 우측 방 목록의 2-컬럼 레이아웃.

- **좌측 — 방 생성 폼**
  - 방 이름 입력 필드
  - 비밀번호 입력 필드 (비밀번호 토글 OFF 시 비활성화 표시)
  - 비밀번호 활성 토글 (ON/OFF)
  - 최대 인원 스테퍼 (- 버튼 / 숫자 표시 / + 버튼)
  - 방 만들기 버튼

- **우측 — 방 목록**
  - 스크롤 가능한 방 목록. 각 행: 방 이름 + 현재 참여자 수
  - 비밀번호 없는 방 행 클릭 시 입장
  - 비밀번호 있는 방 행 클릭 시: 방 목록 위에 비밀번호 오버레이 팝업 표시
    - 오버레이: 비밀번호 입력 필드 + 확인 버튼 + 취소 버튼

- 입력 필드(방 이름, 비밀번호)는 UI 구조만 구성하며 가상 키보드 연결은 추후.
- 백엔드 API 연동 없이 UI 구조·상태만 구현.

## Behavior

- **Given** 사용자가 멀티플레이 패널을 열었을 때
  **When** 패널이 표시됨
  **Then** 좌측 방 생성 폼과 우측 빈 방 목록(플레이스홀더)이 표시됨

- **Given** 비밀번호 토글이 OFF 상태
  **When** 패널이 표시됨
  **Then** 비밀번호 입력 필드가 비활성화(회색) 상태로 표시됨

- **Given** 비밀번호 토글을 ON으로 변경
  **When** 토글 클릭
  **Then** 비밀번호 입력 필드가 활성화 상태로 전환됨

- **Given** 방 목록에서 비밀번호 있는 방을 선택
  **When** 방 행을 클릭
  **Then** 방 목록 위에 비밀번호 입력 오버레이가 팝업으로 표시됨

- **Given** 최대 인원 스테퍼
  **When** + 또는 - 버튼을 클릭
  **Then** 표시된 인원 수가 1 증가 또는 감소

## Out of Scope

- 가상 키보드 연동 (방 이름·비밀번호 입력)
- 백엔드 API 연동 (방 생성, 목록 조회, 입장 처리)
- 인-룸 패널 (참가자 목록, 퇴장) — 별도 sub-spec으로 이후 정의
- 세션 패널 버튼 추가 (→ session-panel sub-spec 08)
