# 접속 현황 UI

**Parent:** [`_index.md`](../_index.md)

## Why

같은 룸에 누가 있는지 알 수 없으면 공유 공간의 사회적 감각이 사라진다. 실시간 접속 현황을 UI로 보여줘야 유저가 함께 있다는 인식을 가질 수 있다.

## What

현재 룸에 접속 중인 유저 목록을 실시간으로 표시하고, 룸 생성·입장·퇴장을 수행할 수 있는 UI를 제공한다. 클라이언트 빌드의 단일 씬 안에 월드스페이스 UI로 통합 제공하며, 룸 입장 전(개인 방) 상태와 입장 후(멀티 합주) 상태는 같은 씬에서 UI/오브젝트 활성화 토글로 전환된다. 룸 목록은 백엔드가 admission 가능 상태로 공개한 룸만 기준으로 표시하고, 접속자 목록은 실제 룸 세션의 실시간 상태를 기준으로 닉네임만 표시한다. 룸 생성 UI는 멀티 룸이 호스트의 마지막 saved 개인 룸 snapshot을 복사해 시작되는 `copy-on-create` 모델을 따른다는 전제를 갖고, 현재 편집 중인 미저장 개인 룸 상태가 자동 반영되지 않을 수 있음을 사용자 경험에 모순 없이 드러내야 한다.

## Behavior

- **Given** 유저가 룸에 입장해 있을 때
  **When** 다른 유저가 입장하거나 퇴장하면
  **Then** 접속 유저 목록이 즉시 갱신된다.

- **Given** 로그인된 유저가 로비 화면에 있을 때
  **When** 룸 목록을 조회하면
  **Then** Spring이 내부 `RoomServerManager`의 현재 active/admission-open 상태를 반영해 공개한 룸들만 표시된다.

- **Given** 유저가 룸 UI에서 입장·퇴장 버튼을 누르면
  **Then** 세션 상태가 변경되고 UI가 즉시 반영된다.

- **Given** 유저가 개인 룸에서 일부 변경을 저장하지 않은 상태일 때
  **When** 룸 생성 UI를 통해 멀티 룸을 만들면
  **Then** 멀티 룸은 마지막 saved 개인 룸 snapshot 기준으로 생성된다.

## Out of Scope

- 유저 아바타 표시 (3D 공간 내 위치)
- 호스트/권한·연결 상태·아이콘 등 닉네임 외 부가 식별 마커
- 클라이언트 측 멀티플레이 전용 씬 분리 (현 시점은 단일 씬 토글 모델만 다룬다)
- 채팅 / 텍스트 메시지
- 유저 초대·친구 목록
